---

## 📌 Disclaimer
> **Important Legal & Operational Notice:** Predictions generated by F.R.A.U.D.S.H.I.E.L.D. indicate *statistical likelihood of potential fraud*, not conclusive proof of criminal activity. Model outputs serve as triage recommendations for human compliance officers and fraud analysts.

---

## 🎯 Project Objectives

1. **Multi-Dataset Support**: Flexible architecture supporting PaySim mobile money logs, credit card datasets, and user-uploaded custom transaction schemas without pipeline cross-contamination.
2. **Leakage-Safe Machine Learning**: Strict separation of training and test distributions, ensuring reliable real-world generalization.
3. **Rigorous Algorithmic Benchmarking**: Comparison across Logistic Regression, Decision Trees, Random Forests, Naive Bayes, Support Vector Machines (SVM), and K-Nearest Neighbors (KNN).
4. **Extreme Class Imbalance Handling**: Calibration using SMOTE, random undersampling, cost-sensitive learning, and precision-recall threshold tuning.
5. **Explainable AI (XAI)**: In-depth SHAP (SHapley Additive exPlanations) attribution to reveal the exact features driving any individual high-risk flag.
6. **Decoupled Architecture**: High-performance FastAPI backend paired with a modern, responsive Next.js analytics dashboard featuring dark and light cyber-fintech themes.
7. **100% Free & Local Execution**: Runs entirely on local consumer hardware without mandatory paid APIs or cloud subscriptions.

## 🚀 Getting Started

### Prerequisites
- Python 3.12+ (Anaconda or standard Python)
- Node.js 18+ and npm
- Git

### 1. Clone & Set Up the Repository
```bash
git clone git@github.com:rafayraza-nextgen/FRAUDSHIELD-ML.git
cd FRAUDSHIELD-ML
```

### 2. Set Up the Python Virtual Environment
```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```
